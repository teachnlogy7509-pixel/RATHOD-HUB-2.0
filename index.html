QUICK HELP

Frequently asked questions

5
Timer और study time कब save होता है?

Timer Finish दबाते ही subject, तारीख और duration save होता है। Offline होने पर data device में सुरक्षित रहता है और internet आते ही sync होता है।

Live room में मेरा नाम कब दिखेगा?

Login करके timer start करते ही आपका नाम live learners में दिखाई देगा। Timer finish करने पर live status हट जाएगा।

Premium या VIP coupon कैसे redeem करें?

Gold VIP Pass खोलें, active coupon code बिल्कुल सही लिखें और Redeem दबाएँ। Invalid दिखे तो admin से active code लें।

Password भूलने पर क्या करें?

Login screen में Forgot password चुनें। अपना name, recovery email और नया password डालकर account recover करें।

Admin या technical help कैसे मिलेगी?

नीचे Contact Us से @Ashish_Thakur1 को Telegram message करें या official YPTSTUDY1 group join करें।
